# 素材スタジオ：入口と制作履歴の改善

2026-11-10 実装・隔離検証。本番状態は AI_Workspace の同日のハブ・スタジオ改善記録で管理する。

- 入口に「原稿 → 比較・採用 → 編集へ」の3ステップを追加。スマートフォンでは小さくまとめ、チャンネルを選ぶ場所を早く見せる。
- チャンネル内の「新しく作る」と「制作履歴へ」を並べ、作業中の回と次の制作を行き来しやすくした。
- 履歴はスペース区切りの複数語、全角/半角をそろえて検索。検索語と状態は同じタブ・チャンネル内で保持し、再読み込み後も復元する。保存不可でも通常操作を続けられる。
- 0件のときは検索解除ボタンを表示。`/` で検索欄へ、入力欄の Escape で条件を解除。ダイアログと他の入力中には `/` を奪わない。
- 案件保存中は送信ボタンを「案件を準備しています…」にし、失敗時に元へ戻す。二重送信の停止は維持する。

生成モデル・料金・同時処理・保存期間・画像・採用・認証は変更しない。検索状態は表示設定だけで、共有の制作記録には書き込まない。
